# E-Commerce Database Management System

## Project Overview

This project uses MySQL to manage and analyze e-commerce data, including customers, orders, products, payments, and shipping.

## 🗄️ Database Structure

The database manages key e-commerce operations involving:

* Customers
* Products
* Orders
* Payments
* Shipping

SQL queries are used to retrieve, analyze, and manage e-commerce data.

## Tools Used

* MySQL
* SQL

## SQL Concepts Used

* Joins
* CASE Statements
* Subqueries
* GROUP BY and HAVING
* Window Functions
* Stored Procedures
* Triggers

## Project Tasks

1. Update customer loyalty points using CASE statements.
2. Analyze country-wise order values.
3. Calculate product quantities by payment method.
4. Identify the top 3 customers by spending.
5. Find products based on total order quantity.
6. Create a stored procedure to retrieve customer orders.
7. Calculate customer spending using a stored procedure.
8. Set default loyalty points using a trigger.
9. Automatically update product stock after an order.

* Practiced SQL queries to analyze e-commerce data.

* Learned to automate database operations using stored procedures and triggers.
